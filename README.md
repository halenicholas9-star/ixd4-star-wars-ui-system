# IXD4 Star Wars UI System

Project foundation built with Vite, React, and TypeScript.

## Development

Requires Node.js 20.19+ or 22.12+ and pnpm.

```sh
pnpm install
pnpm dev
```

## Production

```sh
pnpm build
pnpm preview
```

## Structure

- `src/App.tsx` — minimal starter screen and app shell.
- `src/styles/tokens.css` — initial color, typography, spacing, and layout tokens.
- `src/styles/global.css` — global and starter screen styles.
- `src/main.tsx` — React entry point.

The starter tokens are provisional. Components and documentation pages can be added as the design system develops.
